# BPL Dream 11 🏏

🚀 Live Demo

[View Live Project →](https://bpl-pro-dream-11.netlify.app/)

A React-based cricket player selection application built as a hands-on learning project to practice core React concepts and interactive UI development.

## About the Project

BPL Dream 11 is a practice project inspired by fantasy cricket applications. It allows users to explore player cards, select players, and manage their selections through an interactive interface.

The primary goal of this project was to strengthen my understanding of React fundamentals through practical implementation.

## Features

- Interactive player cards
- Player selection functionality
- Selected player management
- Coin-based player selection logic
- Dynamic UI updates
- Conditional rendering and styling
- Responsive user interface

## React Concepts Practiced

- Functional Components
- Props and Component Communication
- React Hooks (`useState`, `useEffect`, `useContext`)
- Context API for state management
- Lifting State Up
- Conditional Rendering
- Conditional CSS Styling
- Array Methods (`map`, `filter`, etc.)
- Event Handling

## Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- DaisyUI
- React Icons

## Getting Started

To run this project locally:

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd BPL_Deam_Eleven
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```
